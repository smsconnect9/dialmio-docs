Calling & auto dialer

Auto dial from Excel, after-call notes, call recording, follow-up alarms and missed-call callbacks.

Auto dial from Excel

Upload a list and let Dialmio dial it for you — up to 100 numbers with one tap. No more dialling by hand. Full guide with video: Auto dialer.

  1. Tap Auto Dial in the bottom bar.
  2. Import your numbers from an Excel/CSV file, or pick leads already in Dialmio.
  3. Start the session. After each call, fill the after-call sheet and Dialmio moves to the next number.
TipKeep a column for the customer name in your Excel file so the caller sees who they are calling.

After-call sheet

When a call ends, a two-tap sheet lets you save the outcome right away: set the Status, add a Remark and schedule a Reminder. You can do the same later from any call-log entry using the Status Remark Reminder buttons, and see the full timeline with History. Step-by-step: Update status, remark & reminder.

Full customer detail on every call

When a known number calls, Dialmio shows the name, status, last note and next follow-up on screen — caller ID comes from your own records.

Call recording

Dialmio can attach call recordings to the lead on supported Android phones. Recording availability depends on the phone model and Android version.

Follow-up alarms

Every reminder you set rings as an alarm at the right time, and all due follow-ups are listed in the Reminders tab.

Missed-call callback queue

Missed calls are collected in a callback queue so no enquiry is forgotten.

Works with mobile data off

Calling and logging work offline. Data syncs to your account the next time you are online (if backup is on).

Analytics

See call counts, talk time and charts for any date range. Full guide: Call analytics.

App language

Dialmio supports 40 languages. Change it from All Tools → App Language.
