WhatsApp

Auto WhatsApp after every call, bulk campaigns and a shared inbox using your WhatsApp Business API.

Connect your WhatsApp Business API

Dialmio works with any WhatsApp Business API provider. We recommend WappConnect, which connects in a few minutes and supports chatbot automation.

Meta chargesWhatsApp conversation charges are set by Meta and billed by your API provider, not by Dialmio.

Auto WhatsApp after the call

Send an automatic follow-up message the moment a call ends, so no lead goes cold. Set it up from All Tools → Auto WhatsApp and pick an approved template from Templates.

Bulk WhatsApp campaigns

Tap Bulk WA to send a campaign to your leads, to contacts from your call logs, or to numbers you copy-paste. There are two send modes:

ModeHow it sendsUse it for
Server campaign (recommended)Through the Meta WhatsApp Business APIBulk messages — verified and safe for large lists
One by oneOpens your phone's own WhatsApp app for each numberChatting with a single lead after the 24-hour API window has closed
Do not use “One by one” for bulkSending many messages from a normal WhatsApp number can get the number blocked by WhatsApp. Always use Server campaign for bulk.

Shared WhatsApp inbox

Replies that come to your API number appear in the WhatsApp tab. Any chat can be converted into a lead with one tap.

Follow-up series (DRIP)

Create a sequence of messages that go out automatically over several days. Open All Tools → Follow-up series (DRIP).

Automation with WappConnect

When Dialmio is connected to WappConnect, a change in lead stage can trigger a WappConnect chatbot or automation flow — for example, sending a brochure when a lead moves to Interested.
