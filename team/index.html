Help Center › For owners

Team & owner tools

Live dashboard, daily call report, selfie attendance, permissions and team plans.

Add your team

Using Dialmio with a team? Assign leads, give each caller their own list and see everyone's calls. Open All Tools → Team plans to choose a plan and add users.

Live dashboard

See every caller's calls, talk time and lead progress in one place, live.

Automatic daily call report

Get a summary of the day's calls for each team member without asking anyone for it.

Selfie attendance

Team members mark attendance with a selfie and location. Use the Attendance app backup option if a phone should sync only attendance, location and leads.

Permissions

Control what each user can see and do — for example, whether callers can see other callers' leads.

Branches & working hours

Set working hours for each branch. Phones that use Only calls in working hours will then skip personal calls made outside office time.

Unified search

Search a name or number once to find their calls, lead record, notes and WhatsApp chats together.
